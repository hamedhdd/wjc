# Format:  <hijri year>/<hijri month>  <jalali date of day 1 (yyyy/mm/dd)>   [# comment]

# The app derives the Hijri date shown in each cell, and every lunar holiday
# (Tasua, Ashura, Eid al-Fitr, ...), from these month starts. Months not listed
# here fall back to an astronomical crescent-sighting estimate, which can be
# off by one day.
#
# To correct or extend the calendar without recompiling, put a file named
# hijri_months.txt next to wjc.exe using the same format, then restart the app.
# Entries in that file override the ones below.
